# B站粉丝牌助手文档

这是当前项目的本地文档，只保留 Markdown 内容。

## 当前行为

- 开播中的直播间：无论粉丝牌是否已经点亮，都会点赞 30 次，用于获取点赞亲密度。
- 未开播且未点亮的粉丝牌：发送弹幕尝试点亮；未开播时点赞不会点亮粉丝牌。
- 观看直播任务：默认关闭。若要开启，建议设置 `WATCHINGLIVE: 150`，因为当前规则约为每 15 分钟 +1 亲密度，单日上限 +10。
- 报告消息：不再按亲密度获取量分组，只保留未点亮粉丝牌和当前佩戴粉丝牌信息。
